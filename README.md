# Persian Writing Skills & Humanizer Pack ✍️🇮🇷

مجموعه‌ای از مهارت‌ها (Skills)، الگوها، قوانین و ابزارهای نگارش، ویرایش و **انسانی‌سازی (Humanization)** متون فارسی برای هوش مصنوعی و ایجنت‌های نرم‌افزاری (Hermes Agent، Claude، ChatGPT).

این مخزن بر **نثر معیار، زنده، فکت‌محور و بدون رد پای هوش مصنوعی** تمرکز دارد و مجهز به چک‌لیست‌های سئو (On-Page SEO) و سازگار با سیستم‌های ارزیابی مثل **Rank Math** و پلاگین‌های سئو است.

---

## 🌟 چرا این مجموعه؟

بسیاری از مدل‌های زبانی هنگام تولید متن فارسی دچار چند آفت بزرگ می‌شوند:
1. **کلیشه‌ها و اسلاپ هوش مصنوعی (AI Slop):** استفاده مکرر از مقدمه‌های انشایی («در دنیای پرشتاب امروز...»، «اگر به دنبال... هستید»).
2. **صفت‌های بادکنکی و اغراق‌آمیز (Puffery):** غول تکنولوژی، انقلابی، شاهکار، بی‌نظیر، شگفت‌انگیز.
3. **تقارن‌های منفی و سوالات بلاغی تصنعی:** ساختارهای تکراری «نه‌تنها... بلکه»، «شاید بپرسید... در پاسخ باید گفت...».
4. **جملات کش‌دار و مبهم:** پیچیدن چند گزاره در یک جمله بدون رعایت استاندارد تک‌گزاره‌ای.

این پکیج با ترکیب قوانین تجربی از صدها بررسی واقعی فروشگاه‌های ایرانی (دیجی‌کالا و تکنولایف)، اصول زبان کنترل‌شده هوانوردی (**ASD-STE100**) و متدولوژی پروژه پاک‌سازی متون AI ویکی‌پدیا (**WikiProject AI Cleanup**) ساخته شده است.

│   │
│   └── products-extractor/         # 🔍 پایپ‌لاین استخراج فکت از سایت رسمی سازنده

│
├── tools/

    └── samples/

## 🛠️ شرح مهارت‌ها

### ۱. `persian-humanizer` (طبیعی‌سازی متون فارسی)
* **وظیفه:** تبدیل متن‌های ماشینی، پرتعارف یا ترجمه‌وار به نثر روان، مستند و فکت‌محور بدون افتادن به لحن شکسته عامیانه.
* **قوانین کلیدی:**
  * **نشان بده، صفت نباف (Show, Don't Tell):** بیان مکانیزم فیزیکی قطعه به جای صفت کیفی مبهم.
  * **بیان صادقانه محدودیت‌ها (Acknowledge Trade-offs):** اگر محصولی برای کاربری سنگین مناسب نیست، صادقانه ذکر می‌شود.
  * **شروع مستقیم:** حذف مقدمه‌چینی‌های فلسفی و آغاز مستقیم با خود موضوع.

### ۲. `persian-simple-tech` (نگارش فنی ساده و بدون ابهام)
* مبتنی بر اصول ASD-STE100 هوانوردی برای نگارش داکیومنت، مشخصات فنی و دفترچه‌های راهنما:
  * سقف ۲۰ تا ۲۵ کلمه در هر جمله.
  * فقط یک ایده فنی در هر جمله.
  * واژگان ثابت (عدم تغییر مداوم بین پورت، درگاه، ورودی).

### ۳. `persian-product-copywriter` (کپی‌رایتینگ سئو شده)
* پایپ‌لاین یکپارچه برای صفحات محصول ووکامرس:
  * تگ `<h1>` دقیقاً منطبق بر نام رسمی محصول.
  * پاراگراف معرفی اجباری با هدف قصد جستجو (Search Intent).
  * تیترهای `<h2>` کاربردی و بخش سوالات متداول (FAQ).
  * متای توضیحات استاندارد دقیقاً بین ۱۵۰ تا ۱۶۰ کاراکتر فارسی.
  * تست شده با موتور تحلیلی **Rank Math** با دریافت چراغ سبز سئو (امتیاز ۷۸+).

### ۴. `products-extractor` (استخراج فکت)
* تضمین صفر بودن توهم هوش مصنوعی (Zero Hallucination).
* جستجو در سایت رسمی سازنده کالا و استخراج جدول قطعی مشخصات، پورت‌ها، توان‌ها و اقلام جعبه قبل از آغاز نگارش.

## 🔌 یکپارچه‌سازی با ابزارهای سئو (SEO Integration)

این بسته به طور کامل با ابزارهای پیشرفته سئو سازگار است:
* **Rank Math SEO:** الگوی ساختار خروجی طوری کالیبره شده که تمام فاکتورهای `keywordInTitle`, `keywordInMetaDescription`, `keywordIn10Percent`, `keywordInSubheadings`, `keywordDensity` را پاس کند.
* **Hermes SEO Plugin:** سازگار با پلاگین رسمی [`hermes-seo`](https://github.com/yuzushi-dev/hermes-seo.git) جهت آدیت فنی، آنالیز صفحات و ارزیابی رقبا.

## 🚀 نحوه نصب و استفاده در Hermes Agent

### ۱. نصب مستقیم مهارت‌ها:
برای اضافه کردن مهارت‌های این مخزن به هرمس ایجنت، پوشه اسکیل‌ها را در مسیر مهارت‌های هرمس کپی کنید:

```bash
git clone https://github.com/astronuttt/persian-writing-skills.git /tmp/persian-writing-skills
cp -r /tmp/persian-writing-skills/skills/* ~/.hermes/skills/
```

### ۲. فراخوانی در پرامپت:
هرمس به صورت خودکار با توجه به نیاز پرامپت مهارت مرتبط را بارگذاری می‌کند. همچنین می‌توانید صریحاً آن را صدا بزنید:

```text
از اسکیل persian-humanizer استفاده کن و این متن رو طوری بازنویسی کن که بوی هوش مصنوعی نده و صفت‌های تبلیغاتی حذف بشن:
[متن شما]
```

### ۳. اجرای اسکریپت سانیتایزر نیم‌فاصله (Deterministic Sanitizer):
حتی قوی‌ترین مدل‌ها نیز گاهی نیم‌فاصله را از قلم می‌اندازند. می‌توانید خروجی را از اسکریپت بهینه‌شده پایتون عبور دهید:

```bash
python3 tools/sanitizer/sanitize_fa.py input.txt > output.txt
```
